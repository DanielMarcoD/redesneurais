# EDA — Online Shoppers Purchasing Intention Dataset

Este projeto apresenta uma Análise Exploratória de Dados (EDA) do conjunto
**Online Shoppers Purchasing Intention Dataset**.

O objetivo é explorar as variáveis disponíveis e investigar padrões que possam
estar associados à intenção de compra de visitantes de uma loja virtual.

## Dataset

Os dados e sua documentação estão disponíveis no repositório oficial da UCI:

- [Online Shoppers Purchasing Intention Dataset — UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)

## Próximos passos

- Carregar e inspecionar os dados;
- Tratar valores ausentes, tipos de variáveis e possíveis inconsistências;
- Construir visualizações para entender distribuições e relações entre as variáveis;
- Preparar os dados para a etapa de modelagem.
